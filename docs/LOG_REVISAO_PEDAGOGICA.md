## Política de conclusão

Uma página HTML, uma ilustração ou um quiz implementado não comprovam aprendizagem. A aprovação editorial requer revisão técnica, revisão pedagógica, teste com estagiários iniciantes e confirmação dos limites de supervisão. Esta versão é uma prévia **não homologada**.
